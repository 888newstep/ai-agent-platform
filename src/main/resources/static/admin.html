关于项目

AI Agent Platform

基于 Spring Boot 3 + LangChain4j 构建的企业级 AI Agent 平台。

核心特性

  • ReAct Agent 推理循环（Thought → Action → Observation → Final Answer）
  • 多路召回 RAG（向量检索 + BM25 关键词 + RRF 融合）
  • 语义缓存（降低 API 调用成本）
  • 多模型动态切换（策略模式）
  • Multi-Agent 协作（Supervisor + Worker 并行执行）
  • SSE 流式输出（心跳机制保持连接稳定）
  • Docker 一键部署（4 服务编排）

技术栈

Spring Boot 3.5 · LangChain4j 0.34 · Java 17 · MySQL 8 · Redis 7 · Milvus 2.4 · Docker
